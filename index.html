Claw-Fuel 是一款 macOS 選單列應用程式，即時追蹤 Claude AI 的 Session、Weekly 及 Sonnet 額度，在用盡前主動通知你。

下載 DMG 查看原始碼

需要 macOS 15.0 或以上

功能特色

你需要的，全都有

選單列即時顯示

圖示與百分比一目瞭然，依使用量自動變色：綠色代表安全，橘色代表警告，紅色代表即將用盡。

多維度額度追蹤

同時監控 Session（5h）、Weekly（7d）、Sonnet 三種額度。

趨勢圖表

24h / 3d / 7d 歷史用量走勢，面積圖與折線圖切換。

用量預測

根據目前速率推算額度耗盡時間，提早規劃使用策略。

智慧通知

用量達 90% 發出警告，額度重置時自動提醒你恢復使用。

自動更新

內建 Sparkle 更新機制，有新版本時自動通知並一鍵安裝。

開機自動啟動 · 雙語支援

支援 macOS 原生「登入時啟動」，開機即在背景默默守護你的額度。繁體中文與英文完整在地化，自動跟隨系統語言。

安裝指南

三步驟開始使用

1

下載 DMG

前往 Releases 下載最新版本，開啟 DMG 並將 Claw-Fuel.app 拖入 Applications 資料夾。

2

移除隔離屬性 （必要步驟）

由於 App 未經 Apple 公證，首次開啟前請在終端機執行以下指令，否則 macOS 會阻擋啟動：

xattr -cr /Applications/Claw-Fuel.app
3

開啟 App 並登入

點擊選單列圖示，選「連接 Claude」，以你的 Claude 帳號登入即可開始追蹤用量。
